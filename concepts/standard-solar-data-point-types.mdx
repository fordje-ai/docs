title: "Standard solar data point types"
description: "Standard data point types for Residential Solar and C&I Solar"
---

A data point type is a regulatory question that Fordje asks consistently across jurisdictions. The value is the answer for a specific Authority Having Jurisdiction (AHJ). For example, `Permitting - Solar Permit Cost (Residential)` is a data point type, while a jurisdiction's published permit fee is its value.

The sets below are the standard data point types Fordje recommends for Residential Solar and C&I Solar. Use the IDs with `data_point_type_ids` when you [query data points](/concepts/data-points) or [generate a report](/concepts/reports).

<Info>
  These curated sets are not the complete data point type catalog. They also do
  not guarantee that every AHJ has a published value for every type. Use `GET
  /v1/data-points/types` to retrieve the complete current catalog. See the [API
  reference overview](/api-reference/introduction#data-points) for the endpoint.
</Info>

Production IDs and names on this page were verified on August 25, 2026.

## Use the IDs in a report

Pass one of the arrays above as `data_point_type_ids` when you generate a matrix report. This abbreviated example uses three Residential Solar types:

```bash
curl -X POST "https://connect.fordje.com/v1/reports/matrix" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "ahj_ids": [101, 205],
    "data_point_type_ids": [33, 49, 19]
  }'
```

<Note>
  If an AHJ does not have a published value for a requested type, its matrix
  cell is returned as `null`. Handle `null` values when you process report
  results.
</Note>
